# 作品集项目设计规范
> 项目：前端作品集深色风格网站，所有新页面必须遵循本规范，保证视觉统一

## 1. 配色规范
| 类型 | 色值 | 说明 |
| ---- | ---- | ---- |
| 背景色（主背景） | `#0b1416` | 页面全局深色背景 |
| 卡片背景色 | `#122023` | 项目卡片默认底色 |
| 卡片悬浮背景 | `#162a2d` | hover卡片时背景 |
| 主文字色 | `#ffffff` | 标题、重点文字 |
| 次要文字色 | `#b8c3c6` | 正文描述文字 |
| 红色点缀（主点缀） | `#ef4444` | 红点、主按钮 |
| 蓝色点缀（辅助） | `#3b82f6` | 标签、次要强调 |
| 边框颜色 | `rgba(255, 255, 255, 0.08)` | 卡片默认边框 |
| 卡片悬浮边框 | `rgba(239, 68, 68, 0.25)` | hover卡片边框色 |

## 2. 字体规范
全局字体栈：`'Segoe UI', system-ui, -apple-system, sans-serif`
- 大标题（Hero标题）
  - 字号：`clamp(1.8rem, 4vw, 2.4rem)`
  - 字重：700
  - 行高：1.3
- 区块标题（My Projects）
  - 字号：1.8rem
  - 字重：700
- 卡片标题
  - 字号：1.2rem
  - 字重：600
- 正文描述文字
  - 字号：0.95rem ~ 1.1rem
  - 字重：400
  - 行高：1.7
- 标签小字
  - 字号：0.8rem
  - 字重：600

## 3. 间距规范
### 模块上下间距（区块）
- Hero区块上下内边距：`padding: 2.5rem 1.5rem`
- Projects区块上下内边距：`padding: 2.5rem 1.5rem`
### 内部间距
- 区块标题下方外边距：`margin-bottom: 2rem`
- 卡片网格横向间隙：`gap:1.5rem`
- 卡片内部padding：`padding:1.2rem`
- 卡片标题下方：`margin-bottom:0.6rem`
- Hero标题底部间距：`margin-bottom:0.8rem`

## 4. 组件样式规范
### 项目卡片
- 圆角：`20px`
- 边框：`1px solid rgba(255,255,255,0.08)`
- 悬浮效果：`transform: translateY(-8px)`，增加阴影 `0 20px 40px rgba(0,0,0,0.35)`，边框变色
- 图片：`height:220px; object-fit:cover`，底部带分割边框

### 按钮（当前页面已移除，保留规范备用）
- 圆角：`999px`（胶囊形）
- 主按钮背景：`#ef4444`，hover `#dc2626`，上浮2px
- 次要按钮：透明背景，白色半透明边框

### 标签Tag
- 圆角：`999px`
- 背景：`rgba(59, 130, 246, 0.12)`
- 文字颜色：`#93c5fd`
- 内边距：`0.35rem 0.85rem`

### 导航栏（当前无导航，备用）
- 背景：透明/半透明深色
- 文字：白色，hover带颜色过渡

## 5. 通用规则
1. 全局开启平滑滚动：`scroll-behavior: smooth`
2. 盒子模型统一 `box-sizing: border-box`
3. 响应式：768px断点，卡片网格自动变为单列
4. 渐变背景：径向渐变蓝+红弱光晕，叠加主背景色
